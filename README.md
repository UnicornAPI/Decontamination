# Decontamination

Плагин для UnicornAPI (серверный фреймворк для SCP: Project 90): деконтаминация лёгкой зоны (ЛЗС) как в SCP: Secret Laboratory. На заданной минуте раунда КПП ЛЗС закрываются, свет гаснет, лифты из зоны стоят, а газ наносит урон всем, кто остался внутри.

> Версия 1.0.0. Нужен UnicornAPI 1.0.0 или новее. Игра SCP: Project 90 0.4.2 [F05].

## Что делает

- **Отсчёт.** Деконтаминация начинается на `StartMinute` (12) минуте раунда.
- **Предупреждения** за `WarningSeconds` (300, 60, 30 и 10 с до начала): броадкаст всем на `BroadcastSeconds` (8 с) с префиксом C.A.S.S.I.E. Начиная с 60 с живые игроки в ЛЗС дополнительно получают личное сообщение на экране.
- **Начало деконтаминации:**
  - двери КПП ЛЗС (уровень доступа Checkpoint) закрываются и запираются (`LockCheckpoints`). Принадлежность КПП к ЛЗС определяется по корню сцены двери, запасной вариант: есть ли лампы ЛЗС в радиусе `CheckpointRadius` (12 м);
  - остальные двери ЛЗС открываются и запираются, чтобы в зоне нельзя было запереться (`OpenAndLockLczDoors`). Шлюзы не трогаются (`SkipAirlocks`);
  - лифты, у которых хотя бы одна сторона в ЛЗС, нельзя вызвать (`LockElevators`). Игрок при попытке видит сообщение (не чаще раза в 3 с);
  - свет в ЛЗС выключается у всех игроков (`LightsOff`). Кто зашёл на сервер во время деконтаминации, получает тёмную ЛЗС через 10 с после входа. В раунд с событием «Блэкаут» свет не трогается;
  - всем броадкаст `StartText`, а живым в ЛЗС личное сообщение `PersonalInside`.
- **Газ.** Каждую секунду всем живым в ЛЗС наносится урон с причиной «Деконтаминация». Урон растёт со временем (см. [Урон газа](#урон-газа)). Не получают урон мёртвые, наблюдатели и команда Watcher (в том числе SCP-035). Зона игрока определяется по ближайшим лампам карты.
- **Возврат.** В конце раунда, при переходе в лобби, по команде `decont stop` и при выгрузке плагина все затронутые двери возвращаются как были (положение и замок), а свет включается обратно тем, у кого его выключали. На старте следующего раунда свет включает сама игра.
- **Мало игроков.** Если задан `MinPlayers` и игроков меньше, отсчёт стоит. Когда игроки набрались, деконтаминация начнётся не раньше чем через 61 с, с предупреждениями.
- **Включение посреди раунда** (`reload`): если время уже прошло или до начала меньше 30 с, деконтаминация начнётся через 30 с (с предупреждениями 30 и 10 с). Отмена через `decont stop` сохраняется до конца раунда и после `reload`.
- Отдаёт сайту минуту начала, настройки КПП и лифтов и краткое описание через `Server.PublicInfo["Decontamination"]`, WebBridge отправляет это в снимке.

## Установка

1. Установлен UnicornAPI.
2. Положить `Decontamination.dll` в `UnicornAPI/Plugins/`, затем `reload` в консоли или перезапуск.
3. Конфиг создаётся сам: `UnicornAPI/Configs/Decontamination.json`.

## Команды

| Команда | Что делает |
|---|---|
| `decont` | статус: через сколько начнётся, сколько уже идёт или отменена; сколько дверей изменено и у скольких игроков выключен свет |
| `decont start [сек]` | начать через N секунд (по умолчанию 30), только во время раунда. Предупреждения больше N пропускаются. Снимает отмену `decont stop` |
| `decont stop` | отменить до конца раунда, вернуть двери и свет. Только во время раунда |
| `decont doors` | диагностика: сколько ламп с зоной на карте, какие КПП закроются, сколько дверей ЛЗС откроется, блэкаут ли в этом раунде, какие лифты заблокируются |
| `decont zone <игрок>` | в какой зоне игрок и его координаты |

`<игрок>` - SteamID64 или часть ника. Команды для консоли сервера (и консоли сайта через WebBridge), своих проверок прав в плагине нет.

## Настройки

`UnicornAPI/Configs/Decontamination.json`. Изменения применяются после `reload`.

| Поле | По умолчанию | Что делает |
|---|---|---|
| `Enabled` | `true` | включить плагин |
| `StartMinute` | `12` | на какой минуте раунда начинается деконтаминация (можно дробное) |
| `WarningSeconds` | `[300, 60, 30, 10]` | за сколько секунд до начала предупреждать |
| `MinPlayers` | `0` | минимум игроков на сервере для деконтаминации (0 - всегда) |
| `LockCheckpoints` | `true` | закрыть и запереть КПП ЛЗС |
| `OpenAndLockLczDoors` | `true` | открыть и запереть остальные двери ЛЗС |
| `LockElevators` | `true` | заблокировать лифты, у которых хотя бы одна сторона в ЛЗС |
| `LightsOff` | `true` | выключить свет в ЛЗС |
| `SkipAirlocks` | `true` | не трогать шлюзы |
| `CheckpointRadius` | `12` | запасной поиск КПП ЛЗС: радиус поиска ламп ЛЗС, м |
| `DamagePerSecond` | `10` | базовый урон газа в секунду |
| `PercentMaxHpPerSecond` | `2` | урон в процентах от максимального HP (берётся больший из двух) |
| `DamageRampPerSecond` | `0.05` | рост урона: 0.05 = +5% от начального каждую секунду |
| `Prefix` | `<color=#FFC940>C.A.S.S.I.E.</color> <color=#9A9A9A>\|</color> ` | префикс броадкастов |
| `WarningText` | `Деконтаминация лёгкой зоны через {time}. Всему персоналу покинуть зону.` | текст предупреждения всем |
| `StartText` | `Деконтаминация лёгкой зоны начата. КПП заблокированы.` | броадкаст при начале |
| `PersonalWarning` | оранжевое «Вы в лёгкой зоне!» и строка про КПП с `{time}` | личное предупреждение тем, кто в ЛЗС (за 60 с и меньше) |
| `PersonalInside` | `<color=#FF3B3B>Деконтаминация!</color>\nВыхода из лёгкой зоны нет` | личное сообщение тем, кто в ЛЗС при начале |
| `ElevatorBlocked` | `<color=#FF3B3B>Лифт заблокирован:</color> деконтаминация лёгкой зоны` | сообщение при попытке вызвать заблокированный лифт |
| `BroadcastSeconds` | `8` | сколько секунд висят броадкасты |

`{time}` подставляется словами: «5 минут», «1 минуту», «30 секунд».

Пример: деконтаминация на 15-й минуте, только при 4+ игроках, газ слабее.

```json
{
  "StartMinute": 15,
  "WarningSeconds": [ 600, 300, 60, 30, 10 ],
  "MinPlayers": 4,
  "DamagePerSecond": 5,
  "PercentMaxHpPerSecond": 1
}
```

## Урон газа

```
урон в секунду = max(DamagePerSecond, MaxHP × PercentMaxHpPerSecond / 100) × (1 + DamageRampPerSecond × секунд с начала)
```

Округляется до целого, минимум 1. С настройками по умолчанию:

| Кто | в начале | через 10 с | через 20 с | через 60 с |
|---|---|---|---|---|
| человек, 100 HP | 10 | 15 | 20 | 40 |
| SCP-049, 3000 HP | 60 | 90 | 120 | 240 |

## Сборка

Нужно: .NET 6 SDK или новее и папка игры с BepInEx (запущенным хотя бы раз) и установленным UnicornAPI.

```
dotnet build -c Release -p:GameDir="D:\Steam\steamapps\common\SCP Project 90"
```

Без `-p:GameDir` сборка ищет `./libs` с той же структурой (`libs/BepInEx/core`, `libs/BepInEx/interop`, `libs/BepInEx/plugins/UnicornAPI/UnicornAPI.dll`). Путь к `UnicornAPI.dll` можно указать отдельно: `-p:UnicornApiDll=...`. Готовый файл: `bin/Release/net6.0/Decontamination.dll`. DLL игры в репозиторий не входят.
